# Usage guide

## Install and run

From the repository root:

```sh
uv sync --locked
uv run main.py
```

Example input:

```text
Enter URL: https://example.com/a/long/path
```

The next line contains the shortened URL returned by the service. The exact result is generated by TinyURL.

The script processes one URL per run. Run it again to shorten another link.

## Which entry point should I use?

Use `main.py`. The separate `src/url_shortener/__init__.py` file is the original generated package scaffold. Its registered `url-shortener` command prints a greeting and does not run the shortener. Both Python files are preserved without changes.

## Troubleshooting

| Issue | Suggested action |
| --- | --- |
| Missing dependency | Run `uv sync --locked` from the repository root |
| Failed shortening request | Check your URL, internet connection, and TinyURL availability |
| Greeting instead of a shortened link | Use `uv run main.py` |

The script does not catch shortening or connection errors, so a failed request may display a Python traceback. It does not maintain a local link history.

## External service

The entered URL is sent to TinyURL to create the shortened link. Use URLs you are comfortable submitting to that service, and follow its terms.
